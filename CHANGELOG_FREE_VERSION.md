# Changelog

## v2.4.0 (2026-10-26)

### New
**Publish on this server.** A new deploy method, **This server**, writes your static site straight into a folder on the same server as WordPress: no FTP account, Connector or outside service. A short wizard picks the folder, checks it, and tests that its address really serves it.

### New
**One domain, set up for you.** If WordPress is installed at the root of your domain, the wizard can move it into a `/wp` folder. Your static site then lives at the root, WordPress at `/wp` (lock it to your editors with Lockdown), and the move can be undone from the dashboard.
